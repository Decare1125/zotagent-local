# 常见问题与排查

| 现象 | 检查顺序 |
| --- | --- |
| 安装后没有入口 | 确认安装的是 XPI、插件已启用、重启了 Zotero；工具菜单打开工作台 |
| 无法开始问答 | 检查本地服务连接、自己的 Codex 登录、账号模型权限、网络与代理 |
| 模型存在却报权限错误 | 模型目录不是账号授权证明，改用账号实际可用模型 |
| 找不到便签目标 | 重新双击黄色便签或从三个点设置目标，核对底部提示；确认仍是同一 PDF |
| 写入笔记提示未选中 | 在 Zotero 选中已有笔记再写；确实需要新的内容时用“新建文献笔记” |
| 写入内容不是预期回答 | 查看回答选择状态，取消旧选择；无选择时默认最新一次回答 |
| 全文为空 | 检查 PDF 是否为扫描图片、受保护文档或未下载附件；不要假定已 OCR |
| 首次翻译准备很久 | 查看环境状态；需要下载 Python、依赖和模型，确认网络及磁盘空间 |
| Google 429 / 验证页 | 服务限流或要求验证，等待后重试或切换可用服务；不是重装插件即可解决 |
| Bing 任务失败 | 阅读完整错误；若提示 BabelDOC / already translated，改选原始 PDF；其他错误按日志排查 |
| OpenAI / DeepSeek 失败 | 检查该服务 API 密钥、模型名、地址、额度和网络；聊天登录不能替代 API 密钥 |
| 99% 后失败 | 进度估算不保证输出成功；查看最终错误，核对输出是否生成 |
| 关闭翻译窗口仍处理 | 这是后台任务；重新打开后点击停止 / 取消 |
| 后台更新被阻止 | 等待生成完成或停止对应任务，再重新打开工作台 |

报告问题时提供 Windows、Zotero、插件版本，清晰步骤、预期 / 实际结果、脱敏错误文本。不要直接上传完整用户目录、原始文献、认证文件或带密钥的日志。

免费渠道是否可用由网络和供应商决定；不承诺所有地区、所有服务始终可用。运行停止不能撤销已经发往供应商的请求或费用。

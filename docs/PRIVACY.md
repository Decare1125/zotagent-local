# 数据、账号与隐私

## 本机保存

插件在当前 Zotero 配置目录的 `zotagent-local` 中保存配置、会话、项目、上下文附件副本、翻译历史和结果，以及自动准备的运行环境。用户可在界面查看工作目录。Zotero 注释 / 笔记本身保存在 Zotero 数据中，可能按用户自己的 Zotero 同步设置同步。

本地后台只监听回环地址，使用随机令牌。不要把带令牌的访问链接、配置文件或调试输出分享给别人。

## 会发给谁

发送问题时，选中的文献文本、图片、附件和相关会话会交给所选 Agent / 模型服务。PDF 翻译时，文档处理后的文本会交给选择的翻译源。下载环境时会访问组件与依赖分发源。各服务自身的数据政策由供应商规定。

本项目没有共享开发者账号供使用。每位用户使用自己的认证和额度；不要把开发者的本机登录文件打包分发。

## 密钥与登录

Codex 登录使用官方账号授权流程，登录凭据由 Codex 管理。付费翻译 API 密钥目前以明文写入本机配置和引擎 TOML。不要共享这些文件；在共享电脑上使用前应评估访问权限。

## 备份、清理与问题报告

备份时分别考虑 Zotero 库与工作台数据。清理前停止运行任务，核实目标目录并保留需要的笔记和翻译文件。卸载插件不代表已清理历史或供应商数据。

公开 Issues 只发脱敏步骤与错误摘要，不要发账号配置、API 密钥、私人文献和个人信息。演示素材使用独立合成文献库和预设回答，没有发布开发者的私人文献或账号。

# ZotAgent Local 1.0.0 📚

在 Zotero 中连接自己的 Codex，把论文阅读、提问、注释和笔记串起来。

## 本次发布

- PDF 选区、全文、截图与多文献上下文问答。
- 模型及思考强度选择，三档阅读字体。
- 回答多选、范围选择；便签写回答，笔记保存对应问答。
- PDF 黄色便签定位与写入，已有笔记写入和明确新建文献子笔记。
- 项目与会话管理、拖动归档、重命名、搜索。
- 独立 PDF 翻译窗口，双语对照、进度、历史与停止任务。
- Windows x64 内置运行组件，首次翻译可按提示准备环境。

## 安装

下载 `zotagent-local-1.0.0.xpi`，在 Zotero 插件管理器“从文件安装插件”，重启后从工具菜单打开。每位用户使用自己的 Codex 账号；翻译 API 密钥独立配置。首次部署翻译环境需要网络。

## 下载内容

- XPI：Windows x64 插件安装包，约 219 MB。
- source.zip：对应源码和文档，不包含个人数据或预下载运行组件。
- SHA256SUMS.txt：文件完整性校验值。

主要在 Windows x64 + Zotero 10.0.3 验证；其他版本尚未逐一测试。免费翻译可能限流，付费服务并未全部进行真实计费验证。密钥目前明文保存在本机。详细说明见 README、隐私与测试文档。

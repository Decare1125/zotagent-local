# 📖 使用指南

## 1. 从安装到第一次提问

安装发行页的 XPI 并重启 Zotero。在工具菜单打开 ZotAgent Local，进入设置，点击“登录或检查 Codex”，按浏览器提示使用自己的账号授权。账号权限与额度由服务商决定，插件不提供共享账号。

打开论文 PDF，回到工作台点击“同步 Zotero”，确认主文献标题正确。选中 PDF 文字后将其作为选区上下文；需要全文时点击“导入 PDF 全文”。上下文为空时不要假定模型已经看到整篇论文。

可以先问：“解释这段原文，分别列出作者结论、支持证据和你的推断。”核对模型回答与原文，再决定是否写入笔记。

## 2. 模型、字体与会话

选择智能体和当前账号可用模型，再选择支持的思考强度。模型不同，可用档位也可能不同。模型目录仅是可选配置，实际请求仍受账号权限限制。

小、中、大调整阅读界面字体，偏好在本地保存。新对话用于开始独立主题；点击顶部标题可编辑名称，也可在侧边栏会话的三个点中重命名。新建项目后可把会话拖入项目，拖到“其他对话”区域可移出。项目只组织对话，不会移动 Zotero 文献。

## 3. 上下文按钮分别做什么

| 按钮 | 用途 | 需要注意 |
| --- | --- | --- |
| 导入 PDF 全文 | 把当前 PDF 提取的文本加入上下文 | 扫描版可能没有可提取文本；长文会占用更多上下文 |
| 导出 PDF 文本 | 导出提取文本，方便核对或另行处理 | 不等同于导出原 PDF |
| 添加已选文献 | 把 Zotero 当前选中的文献加入本次参考上下文 | 不会自动在论文中插入正式参考文献 |
| 搜索文献库 | 搜索本地 Zotero 条目并添加为参考上下文 | 不是互联网学术搜索；加入后仍要核对是否需要附全文 |
| 添加附件 | 向问题补充本地图片或文件 | 可读格式和视觉能力取决于所选 Agent / 模型 |
| 截图 | 把需要讨论的 PDF 图表区域加入上下文 | 跨页内容可分成多张，发送前检查缩略图 |
| 同步 Zotero | 更新当前文献、阅读选区与工作台上下文 | 是本机状态刷新，不是 Zotero 账号的云同步 |

将不相关或敏感材料移除后再发送。不要把“已经添加”理解成模型一定完整读懂了附件。

## 4. 选择需要保存的回答

每个回答旁的小圆圈可以单独选择，重复点击取消。“选择到此”可选取一段连续范围。底部显示选择状态；“清除选择”回到默认状态。

- 未选回答：使用最新一次回答。
- 选择若干回答：按对话顺序组合所选内容。
- 写入便签：只写回答。
- 写入 / 新建笔记：自动包括各回答对应的问题。时间采用提问时间，不是导出或截图时间。

## 5. 把回答留在 PDF 黄色便签

先在 PDF 中建立黄色便签，再用以下任一入口指定目标：

1. 在 PDF 页面双击目标黄色便签，适合按页面位置定位。
2. 在左侧注释列表，通过摘要找到目标，点击三个点并选择“设为 ZotAgent 写入目标”。
3. 点击便签标题处的“写入 ZotAgent 回答”按钮。

回到工作台，检查底部“写入目标”的页码与提示，然后点击“写入当前注释”。这是向便签评论追加内容，不是新建文献笔记。上述入口由本插件提供，不是所有 Zotero 插件都会出现的系统按钮。

如果切换了论文、关闭阅读器或删除了目标，请重新指定。错误时先核对目标，避免向另一条注释写入。

## 6. 写入已有笔记与新建笔记

在 Zotero 中选中或打开目标笔记，再点“写入已选笔记”。如果没有笔记或没有选中，会提示你选择或新建；不会自动创建重复笔记。

“新建文献笔记”是明确的创建操作，保存到当前主文献下。在 Zotero 文献列表展开文献即可找到子笔记。保存前确认选择的回答，以及当前绑定的主文献。

“复制 Markdown”把选中内容或默认最新回答复制到剪贴板，适合粘贴到其他编辑器。

## 7. PDF 对照翻译

点击顶部“PDF 对照翻译”，或在文献列表右键选择“ZotAgent-PDF 翻译”。独立窗口可载入当前 / 已选文献或搜索本地文献，选择要处理的原始 PDF。

首次先准备翻译环境，等待就绪。设置中选择引擎、翻译源和原文语言。聊天 Codex 账号不等于 OpenAI 翻译 API 密钥；两者独立，API 费用也单独计算。免费服务不需密钥但可能限流。

选择处理方式、目标语言后开始。任务页显示排队、处理、完成或失败；不需要的排队任务可取消，运行任务可停止。关闭窗口不会等于停止。停止之前已发出的云请求可能仍产生费用。

完成后按设置添加结果为文献附件，也可在历史查看。提交原 PDF，避免用已生成的双语 / BabelDOC PDF 再次处理。始终检查译文、公式和分页；不要仅因任务完成就认为学术翻译完全准确。

## 8. 本地保存与后台服务

底部“已保存”指会话在本地落盘的时间，不表示内容已写入笔记。注释和笔记写入有各自的成功提示。工作目录栏可复制路径；会话、附件副本和翻译环境位于当前 Zotero 配置目录的 `zotagent-local` 下。

“本地服务已连接”表示工作台后台通信正常。服务负责调用 Agent、保存会话和管理翻译任务。界面关闭后某些任务仍运行，需使用停止按钮结束任务。Windows 版本使用内置运行组件，正常使用不需要保持 WSL 或 Ubuntu 终端窗口打开。

## 9. 更新与备份

更新前备份 Zotero 数据库以及 `zotagent-local` 用户数据目录，完成运行任务后安装新 XPI 并重启。不要在仍生成回答或翻译时强制替换后台。当前没有公开自动更新服务。卸载插件不等同于删除本地历史；如需清理，先备份并确认目录用途。

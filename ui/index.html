文献、附件和保存如何使用？
添加已选文献：把 Zotero 列表中选中的论文加入本轮对照材料。搜索文献库：查找已有论文，再添加作对照。两者都不会生成引用列表或导入新文献。
添加附件：把图片、PDF 或文本交给智能体分析；图片可直接用于视觉分析，其他文件由智能体按需读取。
同步 Zotero：刷新当前文献和选区，不是 Zotero 云端同步。已有会话的主文献保持锁定，切换论文请新建会话。
每条回答左侧圆圈用于多选。“选择到此”选中两次点击之间的回答。选中回答时，笔记同时包含对应的问题，便笺只写回答。未选择时使用最新一轮内容。新建文献笔记会创建子笔记；写入已选笔记需要先打开目标笔记。
Agent 沿用各自的本地登录。Claude Code 和 OpenCode 需要先在本机安装并登录；未安装时会显示明确提示。Codex 的命令与文件审批会在聊天中显示。
